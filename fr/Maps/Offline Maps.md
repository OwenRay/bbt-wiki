## Introduction

Ce guide vous aidera à comprendre comment utiliser les cartes hors ligne dans votre application Baitboats. Les cartes hors ligne sont très utiles lorsque vous pêchez dans des zones avec une mauvaise connexion Internet ou lorsque vous souhaitez économiser vos données mobiles.

## Types de cartes hors ligne

| Cartes régionales | Google Maps |
|:----------------------------------------------------|:-------------------------------------------|
| Peuvent être téléchargées pour des provinces ou pays entiers | Peuvent être téléchargées pour de petites zones |
| Fonctionnent complètement hors ligne | Sont composées de nombreuses images appelées 'tuiles' |
| Affichent les caractéristiques du terrain (collines, rivières, lacs) | Incluent une option de vue satellite |
| Fichiers généralement plus petits que Google Maps | Couvrent le monde entier |
| Contiennent généralement plus de détails sur la forme des plans d'eau | Fichiers plus volumineux que les cartes régionales |
|  | Sont téléchargées avec un niveau de zoom limité |

## Téléchargement des cartes hors ligne

### Comment télécharger des cartes régionales

1. Allez dans l'onglet Settings (icône d'engrenage).
2. Appuyez sur "Offline Maps".
3. Sélectionnez "Region Maps".
4. Parcourez la liste des cartes disponibles.
5. Appuyez sur la carte que vous souhaitez télécharger.
6. Attendez que le téléchargement soit terminé.

### Comment télécharger des cartes Google Maps

1. Allez dans l'onglet Settings (icône d'engrenage).
2. Appuyez sur "Offline Maps".
3. Sélectionnez "Google Maps".
4. Naviguez jusqu'à la zone que vous souhaitez télécharger.
6. Appuyez sur le bouton de téléchargement.
   - **Note :** L'application ne télécharge que le type de carte que vous visualisez actuellement. Si vous voulez les trois types, vous devez télécharger chacun séparément.
7. Donnez un nom à votre zone de carte.
8. Appuyez sur "Save" pour lancer le téléchargement.
   - Une boîte de dialogue de progression vous indiquera combien de tuiles ont été téléchargées.
   - L'application reviendra à l'écran principal une fois le téléchargement terminé.

## Vérification de la progression du téléchargement et vérification

### Pour les cartes régionales

* Vous verrez un indicateur de progression circulaire montrant la partie de la carte déjà téléchargée.
* Nous vous recommandons d'attendre la fin du téléchargement avant de quitter la page.
* Une fois terminé, une croix (X) s'affichera, permettant la suppression de la carte.
* Vous pouvez continuer à utiliser l'application pendant le téléchargement des cartes.

### Pour Google Maps

* Une boîte de dialogue de progression affiche le nombre de tuiles téléchargées et le nombre total de tuiles.
* Vous devez garder l'écran de téléchargement ouvert jusqu'à la fin de l'opération.
* Vous pouvez visualiser et vérifier vos zones téléchargées :
  1. Ouvrez l'écran de téléchargement de Google Maps.
  2. Appuyez sur l'icône de menu pour voir la liste des zones enregistrées.
  3. Zoomez et dézoomez sur la carte. 
  4. Les zones téléchargées sont indiquées par un **cercle vert avec une coche**.
  5. Si vous zoomez ou dézoomez et que les coches disparaissent, cela signifie que ce niveau de zoom spécifique n'est pas téléchargé.

## Quand utiliser quel type de carte

### Utiliser les cartes régionales quand :

* Vous avez besoin d'informations détaillées sur l'eau.
* Vous avez un espace de stockage limité sur votre appareil.
* Vous pêchez dans les eaux intérieures, les lacs ou les rivières.
* Vous voulez un chargement plus rapide des cartes.
* Vous ne voulez pas vous soucier de l'emplacement précis et préférez télécharger un pays ou une province entière.

### Utiliser Google Maps quand :

* Vous voulez utiliser la vue satellite pour voir les photos réelles de la zone.
* Vous êtes plus familier avec l'apparence de Google Maps.
* Vous savez exactement où se situe votre plan d'eau lorsque vous téléchargez la carte.

## Changer l'ordre des cartes

L'application peut utiliser les deux types de cartes et choisira automatiquement laquelle afficher en fonction de vos réglages.

### Comment changer l'ordre des cartes :

1. Allez dans l'onglet Settings.
2. Appuyez sur "Offline Maps".
3. Devant chaque option, vous verrez une petite poignée.
4. Faites glisser la poignée pour changer l'ordre.

### Ce que signifie l'ordre des cartes :

* La première carte dans l'ordre est essayée en premier lors de l'affichage d'un emplacement.
* Si la première carte n'a pas de données pour cette zone, la deuxième carte est utilisée.
* Placer Region Maps en premier signifie que l'application préférera les utiliser lorsqu'elles sont disponibles.
* Placer Google Maps en premier signifie que l'application préférera les utiliser lorsqu'elles sont disponibles.

## Notes importantes

### À propos de Google Maps et de la vue satellite :

> **Important :** La vue satellite n'est disponible qu'avec Google Maps et n'est pas supportée actuellement pour les cartes de profondeur.
>
> {: .warning}

### Conseils pour de meilleures performances :

* Téléchargez les cartes de vos zones de pêche avant de quitter la maison.
* Conservez les deux types de cartes pour les zones importantes afin d'assurer une couverture optimale.
* Supprimez les cartes dont vous n'avez plus besoin pour économiser de l'espace de stockage.
* Pour les informations de profondeur, utilisez la vue carte standard plutôt que la vue satellite.
